🚀 QUICK START
════════════════════════════════════════════════════════════════════

Step 1: Register HTTP Interceptors (5 min)
────────────────────────────────────────────
  1. Open src/app/app.module.ts
  2. Add to providers array:
     {
       provide: HTTP_INTERCEPTORS,
       useClass: HttpRetryInterceptor,
       multi: true
     }
  3. Repeat for HttpAuthInterceptor and HttpLoggingInterceptor

Step 2: Inject Service in Component (1 min)
────────────────────────────────────────────
  constructor(private appIntegration: AppIntegrationService) {}

Step 3: Use State in Template (1 min)
────────────────────────────────────────────
  {{ (appIntegration.selectIsLoading() | async) ? 'Loading...' : 'Ready' }}

Step 4: Handle Errors (1 min)
────────────────────────────────────────────
  this.appIntegration.fetchChallenges().subscribe({
    next: data => { /* success */ },
    error: error => { /* handle error */ }
  });

Total: ~8 minutes to get started!
